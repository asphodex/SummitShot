# Summit Shot

Браузерная игра-лучник с видом сверху (2.5D) в духе **Archero** и в стилистике **PEAK**.
Герой поднимается на гору снизу вверх: 35 уровней в сезоне, босс каждые 7 уровней, а на вершине —
вулкан, Лавовый монстр и спасение на вертолёте.

Проект курса **«Проектирование и разработка игровых приложений»**.
Стек: **TypeScript + Phaser 4 + Vite + GitHub Pages**.

**Играть:** https://asphodex.github.io/SummitShot/

## Как играть

Пройди уровень снизу вверх и выйди через проход наверху. Вниз внутри уровня ходить можно,
на предыдущий уровень вернуться нельзя. Убитые враги оставляют опыт: за него даются усиления,
а за победу над боссом — сильная абилка на выбор (1 из 3).

| Действие | Клавиши |
|---|---|
| Идти | WASD / стрелки |
| Стрелять | Пробел (автоприцел в ближайшего врага) / ЛКМ (в курсор) |
| Перекат (тратит выносливость, неуязвимость) | Shift |
| Присесть / проползти под бревном | Ctrl / C / ПКМ |
| Пауза | Esc |
| Пропустить обучение | Enter |
| Показать FPS | F |

Самый первый запуск начинается с короткого обучения (уровень 0).

## Что есть в игре

- **5 биомов за сезон:** Берег → Тропики → Альпы → Меса → Кальдера; у каждого свои враги и босс.
  Во втором сезоне те же места в новой, «ночной» стилистике.
- **Уровни разной длины и раскладки** (открытые, рощи, стены, болота, каньоны);
  каждый уровень — новый микс биомных и общих врагов.
- **13 видов врагов и 5 боссов** с разными паттернами атак.
- **14 усилений за опыт** (очередь стрел, веер, кольцо, орбита, щит, шипы и др.)
  и **14 абилок за боссов** (пробивание, рикошет, яд, молнии, перекаты со стихиями и др.).
- **Смена дня и ночи по мере подъёма:** на закате и ночью тёплые («летние») враги слабеют,
  ледяные — крепнут. Фаза зависит от того, как высоко поднялся игрок, а не от времени.
- **Финал:** катсцена спасения и экран итогов (статистика, враги, билд) со скриншотом «поделиться».
- Сохранение забега в браузере (`localStorage`), чёткая картинка на больших экранах,
  растягивание на весь экран.

## Настройки баланса

Баланс меняется без пересборки в файле [`public/config.jsonc`](./public/config.jsonc)
(JSON с комментариями `//`, у каждого параметра есть описание):

- `dayCycle` — длина фаз суток, их границы и сила тёплых/ледяных врагов в каждой фазе;
- `enemies` — рост HP врагов и HP боссов;
- `progression` — как часто даются усиления и с какого уровня открываются стрелы.

После правки обнови страницу. Неверное значение заменяется значением по умолчанию из
`src/game/constants.ts`.

## Запуск

Нужны **Node.js 22 LTS** (или >= 20.19) и **Git**.

```bash
npm install
npm run dev
```

Проверка и сборка:

```bash
npm run typecheck
npm run build
npm run preview
```

После push в `main` GitHub Actions (`.github/workflows/deploy.yml`) собирает игру и публикует её
на GitHub Pages.

## Структура

```text
public/config.jsonc      # настройки баланса (читаются при запуске)
src/
├── main.ts              # точка входа: читает настройки, запускает игру
└── game/
    ├── config.ts        # конфигурация Phaser, список сцен
    ├── constants.ts     # все игровые параметры и значения по умолчанию
    ├── tuning.ts        # загрузка config.jsonc
    ├── view.ts          # чёткий рендер и размеры экрана
    ├── MenuScene.ts     # главное меню
    ├── GameScene.ts     # игровой цикл: игрок, стрельба, враги, боссы, финал
    ├── EndScene.ts      # итоги забега
    ├── season.ts        # сезоны, биомы, план уровня
    ├── level.ts         # раскладка уровня
    ├── enemies.ts       # враги, боссы и их ИИ
    ├── upgrades.ts      # состояние забега, усиления, абилки, сохранение
    ├── daycycle.ts      # смена дня и ночи
    ├── tutorial.ts      # обучение (уровень 0)
    ├── choice.ts        # экран выбора 1 из 3
    ├── hud.ts           # интерфейс
    ├── textures.ts      # процедурная графика
    └── sfx.ts           # процедурные звуки (WebAudio)
```

Вся графика и звуки генерируются кодом — внешних ассетов нет.
